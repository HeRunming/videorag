# Pilot-0 risk register

**Date:** 2026-09-05  
**Scales:** probability (`P`) and impact (`I`) are 1–5. Exposure = `P × I`. Residual values assume mitigations are executed.  
**Escalation rule:** any residual exposure ≥12 or any legal/ethical blocker is reviewed by the project lead before further annotation or public release.

## Source notes

- LongVidSearch motivates the need to distinguish retrieval planning from answer generation under a standardized interface: https://arxiv.org/abs/2603.14468
- FLARE raises the novelty bar for full-modality retrieval and uses a hard bimodal constraint: https://arxiv.org/abs/2605.10228
- LongVALE demonstrates large-scale fine-grained vision/audio/language event annotation: https://openaccess.thecvf.com/content/CVPR2025/html/Geng_LongVALE_Vision-Audio-Language-Event_Benchmark_Towards_Time-Aware_Omni-Modal_Perception_of_Long_Videos_CVPR_2025_paper.html
- CG-AV-Counting provides clue-grounded audio-visual evaluation: https://openaccess.thecvf.com/content/CVPR2026/html/Lu_AV-Reasoner_Improving_and_Benchmarking_Clue-Grounded_Audio-Visual_Counting_for_MLLMs_CVPR_2026_paper.html
- Ego4D requires acceptance of a dataset agreement: https://ego4d-data.org/docs/start-here/
- EPIC-KITCHENS annotation files state CC BY-NC 4.0; media terms still require separate confirmation: https://github.com/epic-kitchens/epic-kitchens-100-annotations/blob/master/license.txt
- YouTube use must follow current platform terms and applicable rights: https://www.youtube.com/t/terms
- Web multimedia link-rot evidence (>20% unavailable in the analyzed collections): https://link.springer.com/chapter/10.1007/978-3-031-27077-2_37
